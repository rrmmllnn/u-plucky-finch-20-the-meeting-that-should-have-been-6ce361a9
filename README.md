One-line entry for the make.fun competition
[The Meeting That Should Have Been an Email](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9):
write one line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny.

## How it works

`main.py` (packed from the readable `line_src.py` with `makefun compress`)
writes a single fixed joke line to `/output/entry.txt`. The program is
deterministic: every run writes identical bytes. No network, no secrets,
no input data.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Files

- `main.py` — packed entrypoint (≤ 4,096 bytes)
- `line_src.py` — readable source of the entrypoint
- `LICENSE` — MIT
